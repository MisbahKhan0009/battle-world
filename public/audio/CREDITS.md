# Audio credits

Flag Clash ships **no audio files** and uses no background music. Every sound effect (bumps, exits,
elimination shatter, final-2 riser, winner fanfare, intro ticks) is synthesized in code at runtime by
`src/audio/synth.ts`.

- Author: Flag Clash contributors
- License: CC0 1.0 Universal (public domain dedication)
- Source: `src/audio/synth.ts` in this repository

Because the output is generated, it is free of third-party copyright and safe to monetize on
YouTube. If you add your own audio files to this folder, list each one below with its source URL
and license.
